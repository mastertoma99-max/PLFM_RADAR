## 导入整理

- 移除导入器额外生成的空白首页，将实际电路放入与工程同名的原理图。
- 原 EAGLE 的贴片是普通铜矩形。原生导入将其转换成无网络的填充区，填铜时可能与馈线避让，并因最小填充厚度产生圆角。本工程将 128 个贴片保存为有网络的实心铜矩形，保留原始直角及尺寸。
- 根据原 PCB 中明确重叠的铜形状，恢复 128 个贴片及 16 个连接器中心馈电焊盘的网络归属。原导入器将相接的馈线段合并为每列一个网络；名称映射记录在 `verification/import_audit.json`。
- 将原连接器封装保存在工程本地 `.pretty` 库，补齐库引用及原理图符号与 PCB 封装的关联。
- 带入原 EAGLE 的最小间距 0.25 mm、最小线宽 0.20 mm、最小孔径 0.35 mm、铜到板边间距 0.25 mm。未为消除检查报告而屏蔽警告。
- 未整理前的原生 KiCad 导入结果保存在 `verification/native_import/`。

## 检查结果与使用边界

完成填铜后的 KiCad PCB DRC：**0 个错误，0 个未连接项，259 个警告**。

| 警告类别 | 数量 |
| --- | --- |
| 过孔仅连接一层或悬空 | 89 |
| 孔重合 | 3 |
| 丝印压铜/阻焊开窗 | 160 |
| 丝印重叠 | 7 |

保留原始几何，未擅自删除重合过孔或改动接地过孔布置。完整 PCB 检查记录见 `verification/drc.json`。

原理图 ERC 有 17 项：16 个中心馈电引脚未连接、1 个电源输入未驱动。原 EAGLE 原理图本身只画了连接器与接地线，天线贴片和馈线实际在 PCB 中，因此原理图没有完整表达射频网络。对应记录见 `verification/erc.json` 和 `verification/netlist.xml`。**继续设计时，应先补齐原理图中的射频网络，再使用“从原理图更新 PCB”，避免覆盖现有馈电网络。**

保持原四层结构，原 EAGLE 第 3 铜层（KiCad In2.Cu）没有铜对象。导入后的显示板厚 1.6 mm 是导入器默认值；板材、实际板厚、介质层间距及射频性能未经本次导入确认。本工程是格式转换结果，未作为生产放行或射频验证结论。
