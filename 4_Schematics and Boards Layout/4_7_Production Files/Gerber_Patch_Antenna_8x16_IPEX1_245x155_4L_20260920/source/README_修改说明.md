# 8×16 天线 IPEX1 版本

日期：2026-09-20；版本：IPEX1-A1；KiCad 10.0.0。

打开 `Patch_Anetnna_16_8_IPEX1.kicad_pro`。本目录包含 PCB、原理图、本地符号及封装库、规格书、预览和验证记录。原 `KiCad_8x16` 导入工程及 EAGLE 原文件未覆盖。

## 更换结果

16 个原 `142-0731-211` 连接器更换为项目 4×4 天线已使用的 **ECT 电连 818000368，USS RF I 代，三焊脚，H1.25 mm**，物料编码 `YC.DZ.SS00008`。

- 16 个连接器位号、中心位置和顶面安装方式保持；信号焊盘朝向阵列。封装在顶面旋转 180°，没有照搬 4×4 板的底面安装。
- 128 个贴片矩形、贴片间距、板框、4 个安装孔、四层结构、内层平面轮廓、原阻焊开窗，以及原有 95 个过孔保持不变。
- 每路仅在连接器中心前 3 mm 范围内调整原馈线端点，并新增一段 1.00 mm 宽的连接线到 IPEX 信号焊盘。原阵列内的馈线保留。
- 每个座子的两个地脚分别增加 0.40 mm 宽的接地线和就近贯穿地孔，共新增 **32 个孔径/外径 0.40/0.80 mm 的 GND 过孔**，符合本板继承的最小孔径 0.35 mm 规则，并检查与原孔的间距。现有金属化过孔共 127 个。
- 原理图已同步改为 16 个三脚座子，补齐全部 16 路 SIG 网络标签、两地脚及工程物料字段。图上按 PCB 从左至右的列号排列，每路馈入 8 个印制贴片；贴片仍作为 PCB 铜图形保留。
- 本地库为 `PLFM_RF.kicad_sym` 和 `PLFM_RF.pretty`，库表使用 `${KIPRJMOD}` 相对路径。16 个符号与 PCB 封装的 UUID 关联及全部网络节点已核对。

## 封装依据

封装直接复用项目已核对的 `ECT_818000368_IPEX1_1.25mm`，哈希与 4×4 工程的库文件一致。本次再次查看规格书第 7 页推荐 PCB LAYOUT，并核对下列尺寸。

| 本库脚号 | 功能 | 焊盘尺寸，mm | 相对座子中心的位置，mm（本板顶面视图） |
| --- | --- | --- | --- |
| 1 | SIG | 1.00 × 1.05 | 0 / -1.525 |
| 2 | GND | 1.05 × 2.20 | +1.475 / 0 |
| 3 | GND | 1.05 × 2.20 | -1.475 / 0 |

1/2/3 为项目库的电气脚号，不是规格书机械材料表的圈号。保留原库安装面铜禁布区、0.05 mm 阻焊扩展及与焊盘等大的锡膏开口。

规格书副本：`datasheets/ECT_818000368_SPEC_E.pdf`。

PCB 仍有 **156 个警告**：89 个过孔仅连接一层或悬空、3 个孔重合、64 个丝印位于暴露铜区域。原板采用整面顶层阻焊开窗，连接器丝印也处于该开窗内。本次没有为清除报告而屏蔽检查或删除原孔。

ERC 有 **16 个“标签只接一个引脚”警告**：每路 SIG 在原理图中只对应座子的一个引脚，其 8 个实际负载是 PCB 上的印制铜贴片。网络名、PCB 馈线和焊盘的对应关系已独立核对。这不是 PCB 断路结论。

## 使用边界

**818000368 的规格测试频率为 DC～6 GHz，原天线目标为 10.5 GHz。**本次完成接口替换、几何及连接检查，未验证 10.5 GHz 下的连接器/线缆插损、回波损耗、馈电过渡及阵列性能，不构成射频等效替代结论。

保持 245 × 155 mm、4 层结构；In1.Cu 为原 GND 平面，In2.Cu 保持原来的空铜层。显示板厚仍为原导入值 1.6 mm，板材、成品板厚及介质层间距待确认。本次没有套用另一块 4×4 板的 FR4/1.0 mm 生产参数，也未生成新生产光绘。
