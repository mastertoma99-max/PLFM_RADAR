# 70×70 mm 四层天线板：0.30 mm 通孔版本

日期：2026-09-18。版本标识：Via03。此版本由此前四层光绘副本修改而来，原始六层板及此前 Via02 光绘包均保留，未覆盖。

## 本次修改

| 对象 | 原孔径 / 焊盘外径 | 新孔径 / 焊盘外径 | 数量 |
|---|---|---|---:|
| 16 路天线馈电过孔 N$1～N$16 | 0.20 / 0.40 mm | **0.30 / 0.60 mm** | 16 |
| GND 过孔 | 0.30 / 0.50 mm | 0.30 / 0.50 mm，保持原样 | 12 |
| 非金属化安装孔 | 3.20 mm | 3.20 mm，保持原样 | 4 |

28 个金属化过孔全部贯穿四个铜层，不含盲孔、埋孔或激光微孔定义。新馈电过孔名义单边铜环为 `(0.60-0.30)/2=0.15 mm`。GND 过孔名义铜环仍为原来的 0.10 mm。

所有孔位、天线贴片、器件位置、走线和板框保持不变。已重铺两个地平面，避空随馈电过孔焊盘扩大；光绘差异只出现在这 16 个过孔周围。铜层间连接关系保持不变。

## 制造文件与层序

文件前缀统一为 `Phased_Array_Ant_70x70_4L_Via03-`。铜层顺序为：**顶层天线 → GND → GND → 底层连接器**，对应原 EAGLE 铜层 1、2、15、16。

| 文件后缀 | 用途 |
|---|---|
| `F_Cu.gtl` | L1 顶层铜 |
| `In1_Cu.g1` | L2 GND |
| `In2_Cu.g2` | L3 GND |
| `B_Cu.gbl` | L4 底层铜 |
| `F_Mask.gts` / `B_Mask.gbs` | 正反面阻焊开窗 |
| `F_Silkscreen.gto` / `B_Silkscreen.gbo` | 正反面丝印 |
| `Edge_Cuts.gm1` | 板框，按中心线为 70.000×70.000 mm |
| `PTH.drl` | 28 个 0.30 mm 金属化通孔 |
| `NPTH.drl` | 4 个 3.20 mm 非金属化安装孔 |
| `job.gbrjob` | 四层及文件映射，未指定未经确认的制造参数 |

Gerber 为 X2 / RS-274X 兼容格式；钻孔为毫米制 Excellon。所有数据使用同一原点、同一坐标系；底层数据未镜像。钻孔文件孔径是设计标称值，钻头补偿、成品孔公差由板厂按双方确认的加工要求处理。

光绘 ZIP 为以上 12 个文件，加本说明及 `SHA256SUMS_Gerber.txt`，共 14 个文件。未包含锡膏钢网层或独立 IPC-D-356A 电测网表。

## 已完成的检查

- EAGLE 修改仅涉及上述 16 个过孔的孔径和焊盘外径；其他源文件元素一致。
- 修改后的 EAGLE 独立导入结果与交付 KiCad 板的全部走线、过孔及网络一致。
- 重铺铜并重新运行 DRC；原来的 16 条 0.20 mm 孔径小于 0.30 mm 规则的报告已消除，无铜短路、铜间距或铜环违规报告。
- 最终 Gerber 中，新馈电孔焊盘到异网铜的最小实测距离约 **0.2005 mm**，大于原设计 0.10 mm 的间距要求。
- 独立 Gerber 图形连通检查：80 个电气焊盘和 28 个过孔所属的 17 个网络全部连通，未发现网络间短路。
- 实际阻焊开窗检查未发现一个连续开窗同时暴露两个不同网络；双面阻焊、丝印及板框图形与 Via02 版本一致。
- 独立钻孔回读：**0.20 mm 孔为 0 个、0.30 mm 金属化孔 28 个、3.20 mm 非金属化孔 4 个**，坐标与源设计一致。
- 四个铜层的差异全部限制在被修改过孔的局部区域，未发现其他铜图形变化。
- 已查看实际光绘渲染的四层预览。

**DRC 未声称零报告：**KiCad 仍报告 64 条封装阻焊图形相关项目（旧版为 60 条）及 24 条接地焊盘连接项目。EAGLE 连接器封装的铜形状/阻焊形状在 KiCad 中以图形表示，相关报告已结合实际 Gerber 铜连接和开窗几何复核；完整报告在 `verification/drc_Via03.json`，未隐藏或排除报告。本结果不代替板厂 DFM、原生 EAGLE DRC 或射频验证。

## 板厂与射频待确认事项

板材、介质厚度、成品板厚、铜厚、表面处理和孔径公差仍待确认。KiCad 中的 1.6 mm 为导入默认显示值，EAGLE 中继承的介质参数亦不是已确认的四层加工叠层；光绘 job 文件已移除这些默认制造参数。

0.20 mm 贯穿孔并不必然要求 HDI/激光加工；板厂可使用机械钻孔，但板厚、材料、孔径公差和费用会影响工艺选择。0.30 mm 通孔通常有更宽松的加工条件。本次未指定填孔、电镀封盖、盘中孔或其他特殊工艺。

**本次扩大的是天线馈电过孔。**孔径、焊盘和地平面避空改变会影响过孔寄生参数；本次确认的是图形、连接和间距可实现，不是 10.5 GHz 射频性能与原版等效。确定板材及叠层后，应对馈电过渡做电磁仿真或通过打样测试回波损耗/匹配及天线性能。

参考：[PCBWay 钻孔工艺能力](https://www.pcbway.com/capabilities.html)、[嘉立创过孔纵横比与加工说明](https://jlcpcb.com/blog/via-aspect-ratio-critical-pcb-reliability)、[ADI 过孔寄生参数说明](https://www.analog.com/en/resources/analog-dialogue/articles/high-speed-printed-circuit-board-layout.html)。这些是一般能力说明，不代表本板已经获得板厂报价或制造确认。
