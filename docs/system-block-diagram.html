版本关系已分开

50T 原理图确认使用 FT2232H，200T 构建脚本选择 FT601；旧框图的 GPS 与 PA 偏置 DAC 已按当前资料改为 UM982 和 DAC5578。数字平台与阵列 / PA 方案分别选择，选项不表示所有组合已验证。

设计目标与实测边界

10.5 GHz、ADC 400 MS/s 等来自项目设计资料。MCU 默认设置还保留 10.0 GHz，与概述不同；具体频率配置需整机确认。此图整理文件中的结构，不代表射频性能、探测距离或上板测试通过。
